# QCrud usage

QCrud uses `Eril\QCrud\CRUD` as its main entry point. Calls remain `CRUD::`.

- [Getting started](getting-started.md): install, connect, and use helpers.
- [CRUD operations](crud.md): create, read, update, and delete records.
- [Query builder](query-builder.md): filters, joins, subqueries, and pagination.
- [Transactions](transactions.md): immediate and queued writes.
- [Caching](caching.md): configure, enable, and invalidate query cache.

Examples assume the connection from [Getting started](getting-started.md) is registered and the referenced tables exist.
