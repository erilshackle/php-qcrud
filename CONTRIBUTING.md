# Contributing to QCrud

We love your input! We want to make contributing to QCrud as easy and transparent as possible.

## Development Setup

1. Fork the repo and create your branch from `main`
2. Install dependencies: `composer install`
3. Run tests: `composer test`

## Pull Request Process

1. Update the README.md with details of changes if needed
2. Update CHANGELOG.md following Keep a Changelog standards
3. Ensure all tests pass
4. The PR will be merged once you have approval

## Code Style

- Follow PSR-12 coding standards
- Add type hints where possible
- Write meaningful commit messages
- Include tests for new features
